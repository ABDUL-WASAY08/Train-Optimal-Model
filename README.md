TOM is an ML-powered GitHub Intelligence, Documentation, and Developer Recruiter Marketplace Platform. It allows developers to sign in via GitHub, sync their repositories, view language distribution analytics, and manage a professional developer portfolio. The platform enables users to train custom AI models using LoRA, QLoRA, and RAG techniques, sell trained models on an integrated marketplace, and integrate intelligent code completion directly into their workflow via a VS Code extension. Built as a Final Year Project at COMSATS University Islamabad, Abbottabad Campus.
